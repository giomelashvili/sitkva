# Sitkva

A Georgian-language speech and comprehension app for young children (PWA). It runs fully in the browser and works offline.

- Open https://giomelashvili.github.io/sitkva/ — on iPad: Safari → Share → „Add to Home Screen“.
- All records, photos and voice recordings stay on the device (IndexedDB / localStorage). Nothing is sent to a server; there is no analytics.
- Starter photos: Wikimedia Commons, open licences — see `seed-photos/CREDITS.md`.
- Font: Noto Sans Georgian, SIL Open Font License — see `fonts/OFL.txt`.
